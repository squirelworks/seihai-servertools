# Lab page in the window, 2026-11-04

What: start and stop a lab world from the window's Lab page
(`seihai-servertools gui --world DIR --page lab`), which runs the lab plan on
a worker thread (`setup_core::lab_run::LabRun`).

## Setup

- Linux, Xvfb at 1200x800, software GL.
- World folder: `servers/default` (port 14802) and `servers/classic` (port
  14803), both lab settings; `seihai-listserver.toml` with `bind =
  "127.0.0.1"`, `gserver_port = 14970`, `client_ports = [14971]`,
  `silent_list_after_ms = 500`.
- Listserver: the real `seihai-listserver` (main `450c258`), copied into the
  world folder.
- Gserver: a stand-in `gs2emu` shell script that prints two console lines and
  sleeps. No fork build was available in this container.

## Result

1. The page opened with Show plan, Start and a greyed-out Stop.
2. Start: within the 2 s settle time the page showed "Running", the log
   `started listserver, pid N`, `started default, pid N`, `started classic,
   pid N`, `lab world running`, and three console tails: the listserver's
   start lines (listening on 127.0.0.1:14970 and 14971, silent list after
   500 ms, the gserver port check connecting and closing), and each stand-in
   gserver's two lines. The world folder field, Show plan and Start were
   greyed out while it ran.
3. Stop: the page showed "Stopped", each process `signal: 15 (SIGTERM)`, and
   no listserver or stand-in process was left running.

Early exits, a program that cannot start, and dropping the run (closing the
window) are covered by `crates/setup-core/tests/lab_run.rs` with the system
shell as the stand-in server, on all three CI platforms.
