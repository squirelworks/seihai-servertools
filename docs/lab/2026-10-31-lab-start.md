# Lab run: one-step lab start, 2026-10-31

Where: cloud container, Linux, loopback only.

What: `seihai-servertools lab start` (this PR) with the real
`seihai-listserver` (`main` at the time of the run, built with
`cargo build --release`) and a stand-in `gs2emu` shell script (it prints its
arguments and exits on SIGTERM). The fork's real `gs2emu` was not built for
this run.

World: `servers/default` (127.0.0.1:14802) and `servers/classic`
(127.0.0.1:14803), `seihai-listserver` in the world folder, no TOML.

Results:

- `lab start --world <world>` printed the plan, started the listserver, waited
  for 127.0.0.1:14900, then started `default` and `classic`. The listserver
  log: `listening on 127.0.0.1:14900 for gservers and 127.0.0.1:14921,
  127.0.0.1:14922, 127.0.0.1:14923 for clients`, then one link from the
  readiness probe closing without `REGISTERV3` (expected).
- SIGINT to `seihai-servertools`: "Stopping...", both stand-ins logged
  `got TERM`, the listserver stopped, no processes left, exit code 0.
- `start.sh classic` from the world folder: the listserver and only
  `classic` started; SIGINT stopped both.

Not checked yet: the real `gs2emu` registering with the listserver and a
Seihai client getting the list (NEXT.md, Lab track), and Windows
(`start.bat`).

The real-fork run is handed to the team (Squirrel, 2026-10-31): see
`docs/NEXT.md`, "Handed to the team".
